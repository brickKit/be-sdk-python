# be-sdk-python

Python SDK：组件协议的官方 Python 实现。旧版本（0.x，最新代码在 `stage-b` 分支）在分支 `legacy/v0`，标签保留；本主分支按终局设计从零开始（D59），版本从 `3.0.0` 起（A110）。

设计依据：装配项目 [be-assembly-standard](https://github.com/brickKit/be-assembly-standard) 的协议 18 `docs/zh/06-protocols/18-sdk-and-conformance.md` 与组件协议 `be-protocol`。代码随重建逐步加入。
